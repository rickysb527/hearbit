## 0. 設計の前提と優先順位

### 想定利用シーン（優先順）
1. **机での復習**: 単語一覧から聞きたい単語をタップ → 即再生。「聞きたい単語にすぐ戻れる」を最優先で解決する。
2. **散歩中の聞き流し**: 画面を見ずにまとめ音声を流す。ロック画面/イヤホン/片手で前後操作。
3. 移動中・片手操作でも押しやすいこと。

### データモデル（`segments.json` 準拠）
- 単語帳 = `book`（例: "HSK3級単語"）
- ページ = `page`（"001"〜"098" のゼロ埋め文字列）
- 各ページに `segments[]`。1 segment = 1単語（単語→訳→例文2つ）。
- `layout`: `word_with_examples`（例文あり・約14秒）/ `word_only`（訳のみ・約5秒）。
- `type`: `word` / `word+announce`（冒頭アナウンス付き。40ページ）。
- `has_announce`, `word_count`, `duration` はページ単位のメタ。
- 全体規模: 98ページ / 654単語。1ページの単語数は最大16（word_only の 086-090）。

### 設計上のUI含意
- **番号ベース**: テキスト（中国語）は将来拡張。今は「ページ番号 + 単語番号」で辿る。数字が主役なので、数字を大きく・タップしやすく並べる。
- **通し番号を併記**: ページ内番号（1〜N）に加え、単語帳全体の通し番号（例: 全654中の #128）を補助表示すると「あの単語」に戻りやすい。
- まとめ聞き流し（機能B）は**連結済み1本の音声**を再生する前提（iOSロック中の連続再生のため）。UI上は「50語/100語チャンク」を1トラックとして扱う。

## 2. 共通コンポーネント

### 2.1 ヘッダー（全画面共通）

**①ルート（単語帳リスト）はブランドヘッダー**、②③は戻る付きのコンテキストヘッダー。

ルート（①）:
```
┌───────────────────────────────────┐
│ 〜|ıl Hearbit                  ⚙  │   高さ 56px（ロゴ左寄せ）
├───────────────────────────────────┤
│  単語帳                             │   ← 画面見出し（大・太字, 28px）
└───────────────────────────────────┘
```
- 左: 波形アイコン + ワードマーク「Hearbit」。アイコン色＝accent（ティール）、ワードマークは text 色。ロゴ全体の高さ 24px 目安。
- 右: 設定 `⚙`（48×48px）。設定画面は下部タブからも到達（2.4）。
- ヘッダー直下に画面見出し「単語帳」を大きく置く（モック準拠。ヘッダーとは別行の H1）。

下層（②③）:
```
┌───────────────────────────────────┐
│ [‹]   タイトル              [⋯/＋] │   高さ 56px
│       サブタイトル                  │   ← 任意（②「Unit 12 · 50語」等）
└───────────────────────────────────┘
```
- 左: 戻る `‹`。タップ領域 48×48px。
- 中央: 画面タイトル（②=単語帳名「HSK 3級」／③=「聞き流し」）。下に補助のサブタイトル（②=対象Unit・語数、③=「単語のみ · 50語」）を small で。
- 右: コンテキストアクション（②=…メニュー, ③=…メニュー）。48×48px。
- position: sticky, top:0。スクロール時も残す。
- **ブランド色**: ロゴ・戻る矢印・アクションアイコンは accent（ティール）。再生関連ではないため常にティールで、オレンジは使わない（オレンジは「いま再生中」専用）。

### 2.4 下部タブバー（①ルート階層のみ）【⬜未実装（デザイン確定）】
```
┌───────────────────────────────────┐
│      📖              👤             │  高さ 56px + safe-area
│    単語帳            設定           │
└───────────────────────────────────┘
```
- ルート階層に2タブ: **単語帳 / 設定**。選択中はアイコン+ラベルを accent（ティール）、非選択は text-sub。
- ②③（単語帳の中）には下部タブは出さない（ミニプレーヤー/全画面プレーヤーが下部を占有するため）。タブは①のトップにいる時のみ。
- position: fixed, bottom。`env(safe-area-inset-bottom)` を padding に加算。

### 2.2 ミニプレーヤー（②③下部に常駐 / 再生中のみ）【⬜未実装（デザイン確定）】

モック②の下部バーに準拠。**再生中はオレンジ（active）が主役**になる帯。
```
┌───────────────────────────────────┐
│ ⌃  参加            〜|ıl|ı|ıl〜   ⏸ │  高さ 64px
│    参加する / P001·単語3           │  （〜=再生波形アニメ・オレンジ）
└───────────────────────────────────┘
```
- 左端: 展開シェブロン `⌃`（タップで全画面プレーヤーへ拡大。バー全体タップでも可）。
- ラベル: 再生中の見出し。テキスト表示時は「単語（訳）」、番号表示時は「P001 · 単語3」、まとめ再生時は「聞き流し 18/50」。
- 中央〜右: **再生中を示すオレンジの波形アニメーション**（イコライザー風。停止中は静止）。進行の細バー（上端3px）でも可だが、モックは波形を採用。
- 右端: 再生/一時停止ボタン。**再生中はオレンジ塗り**の `⏸`、一時停止中はティール塗りの `▶`。48×48px。
- 前/次はミニでは省略可（全画面で操作）。省略しない場合は右に `[◀◀][⏸][▶▶]` を並べる（各48×48px、間隔8px）。
- タップ（ボタン以外の領域 / シェブロン）で全画面プレーヤーへ拡大。
- Safe-area（`env(safe-area-inset-bottom)`）を padding に加算。
- 色運用: バー背景は surface。**波形と再生/一時停止ボタンだけを active（オレンジ）**にし、それ以外はティール/text系。オレンジ＝いま鳴っている、を一目で伝える。

### 2.3 タップ領域・タイポの基準
- **最小タップ領域 48×48px**（要件44pxに余裕を持たせる）。隣接ボタン間は最低8px。
- 本文フォント 16px 以上。数字グリッドの番号は 20–24px・太字。
- 行の高さ（リスト項目・グリッドセル）56px 以上。

- カードは縦1列（片手スクロール前提）。左に**本アイコンの角丸チップ**（accent-weak 背景 + ティールのアイコン）、右に情報を左寄せ、行末に `›`（シェブロン）。

  - `未分割` → 3行目を「タップして分割を開始」。
  - `分割中` → 3行目をプログレスバー + %（Web Audio 分割中）に差し替え、タップで進捗詳細（中断可）。
  - `準備完了` → 3行目 `✓ オフライン`。カードタップで②へ遷移。
- 下部タブ（2.4）: 単語帳 / 設定。設定タブはテーマ切替・単語帳削除・ライセンス等の入口。

## 4. 画面② ページ/単語一覧（Book）【一部: 番号一覧+タップ再生】

**目的**: ページ→単語を直感的に辿り、聞きたい単語を即タップ再生。

### 4.0 2つのレイアウト（番号表示＝現行 / テキスト表示＝Issue #3の完成形）
- **番号表示（現行・基本）**: テキストデータが無くても動く汎用構成。ページ=セクション、単語=番号グリッド（4.1）。**これを最初に実装する。**
- **テキスト表示リスト型（Issue #3・完成形）**: モック②の姿。単語（中国語）+ 訳 + 再生ボタンのリスト（4.2）。テキスト表示（Issue #3）が入った時に切り替える。
- 検索/フィルターバー（4.3）・再生中ハイライト（4.5）・ミニプレーヤー（2.2）は**両レイアウト共通**。番号表示では検索対象が番号/通し番号になる（テキストが無いため）。

### 4.1 番号表示レイアウト（現行・基本 / ページ = セクション、単語 = 番号グリッド）
```
┌───────────────────────────────────┐
│  ‹  HSK 3級                     [⋯] │
│     Unit 1–20 · 654単語             │  ← サブタイトル
├───────────────────────────────────┤
│  [ 単語   ] [ 聞き流し ]            │  ← タブ / セグメント切替
├───────────────────────────────────┤
│  ページ 001            📢6単語 ▾    │  ← セクションヘッダ(sticky)
│   ┌────┐┌────┐┌────┐┌────┐        │
│   │ 1  ││ 2  ││ 3  ││ 4  │        │  番号セル 72×64px
│   │#1  ││#2  ││#3  ││#4  │        │  下段=通し番号(小)
│   └────┘└────┘└────┘└────┘        │
│   ┌────┐┌────┐                     │
│   │ 5  ││ 6  │                     │
│   └────┘└────┘                     │
│  ページ 002             6単語 ▾     │
│   ┌────┐┌────┐┌────┐┌────┐        │
│   │ 7  ││ 8  ││ 9  ││ 10 │        │
│   └────┘...                        │
├───────────────────────────────────┤
│ ⌃ P001·単語3   〜|ıl|ı〜        ⏸ │  ← ミニプレーヤー(2.2)
└───────────────────────────────────┘
```
- **セクション = ページ**。sticky ヘッダに `ページ NNN`、`単語数`、アナウンス有ページは `📢`。
- **番号セルのグリッド**: 横4列（狭幅端末では自動で3列）。1セル 72×64px（十分なタップ領域）。
  - 上段: ページ内番号（1〜N, 24px 太字）。
  - 下段: 全体通し番号（`#128`, 12px 補助色）。
- word_only ページ（最大16単語）でもグリッドが折り返して1画面に収まりやすい。
- セクションヘッダの `▾` でページ単位に折りたたみ可（長い単語帳のスクロール軽減）。

```

│  ‹  HSK 3級                     [⋯] │
```

## 5. 画面③ 再生（Player）【一部: 機能A基本再生のみ】

### 5.1 全画面プレーヤー（機能A: 単語再生）
```
┌───────────────────────────────────┐
│  ⌄                            [⋯]  │  ← ⌄ で下げてミニ化
├───────────────────────────────────┤
│                                     │
│                                     │
│            ページ 001               │  16px 補助色
│                                     │
│               3                     │  ← 大きく単語番号 (64px)
│              #128                   │  通し番号 20px
│                                     │
│         単語 → 訳 → 例文            │  再生中ブロックの目安(任意)
│                                     │
│                                     │
│   0:04 ●━━━━━━━━━━━━━━━ 0:14      │  ← シークバー 全幅・つまみ大
│                                     │
│                                     │
│      ┌────┐  ┌──────┐  ┌────┐      │
│      │ ◀◀ │  │  ⏸   │  │ ▶▶ │      │  主コントロール

│                                     │

```
- **中央に大きな単語番号**（画面を見ずとも一瞬で現在地把握 / 見たとき即認識）。
- **◀◀ / ▶▶ は「前の単語 / 次の単語」**（ページを跨いで連続移動）。長押しでシーク（早送り/早戻し）も可（任意）。
- 再生ボタンは最大（72px）で中央、親指の自然位置。前後は左右対称。
- シークバーのつまみは 24px 以上（片手でも掴める）。タップでその位置へジャンプ。
- 補助行（速度・リピート）は主コントロールより下、誤操作しにくい位置。**速度・リピートは任意機能**。最初は非表示でも可。

### 5.2 再生中ハイライトと進行表示
- 全画面: シークバーが単語内の進行（0:00→length秒）を示す。進行部分は**オレンジ（active）**。
- 一覧②に戻ると、再生中セル/行が **淡いオレンジ塗り（active-weak）+ オレンジの ⏸/波形**（§6.0・4.5）。
- ミニプレーヤー: 再生中の**オレンジ波形アニメ**＋ ⏸ で状態を示す（2.2）。ラベルは番号表示時 `P{page}·単語{n}`、テキスト表示時「単語（訳）」。
- **アナウンス付き単語**（`word+announce`）は冒頭にアナウンスが入る旨を小アイコン `📢` で示す（任意）。

### 5.3 全画面プレーヤー（機能B: まとめ聞き流し）— 円形プログレス【⬜未実装（デザイン確定・モック③準拠）】

散歩中に**画面をチラ見しただけで進捗が分かる**よう、横バーではなく**円形プログレスリング**を採用（モック③）。
```
┌───────────────────────────────────┐
│  ‹            聞き流し        [⋯]  │
│               単語のみ · 50語        │  ← サブタイトル
├───────────────────────────────────┤
│                                     │
│           ╭───────────╮  ●         │  ← 円形リング(直径≈220px)
│          ╱  〜|ıl|ıl〜  ╲           │    ティール基調・進捗分だけ橙弧
│         │               │           │    弧の先端に橙ドット(現在位置)
│         │     参加      │  ← 中央: いま鳴っている単語(大 40px)
│         │    参加する    │  ← 訳(text-sub) ※テキスト有時
│          ╲             ╱            │    番号表示時は「単語 18」等
│           ╰───────────╯             │
│                                     │
│              18 / 50                │  ← 何語目 / 総数(20px)
│                                     │
│      ┌────┐  ┌──────┐  ┌────┐      │
│      │ ⏮ │  │  ⏸   │  │ ⏭ │      │  中央=橙円(72px), 前後=白丸(56px)
│      └────┘  └──────┘  └────┘      │
│                                     │
│        [  50語  ] [  100語  ]       │  ← 粒度トグル
│                                     │
│              ✓ オフライン            │
└───────────────────────────────────┘
```
- **1本の連結音声**を再生。円形リング＝チャンク全体の進行。リング背景トラック＝ティール、経過分の弧＝**オレンジ（active）**、弧の先端に**オレンジのドット**で現在位置を示す。
- 円の中央: **いま鳴っている単語**（テキスト表示時は中国語+訳、番号表示時は「単語 18」/通し番号）。上部に小さな再生波形（橙）。画面を見た瞬間に「何を聞いているか」が分かる。
- リング直下に **`18 / 50`**（何語目/総数）。数字でも進捗を明示。
- コントロール: `⏮ 前の単語 / ⏸ 一時停止 / ⏭ 次の単語`。中央の再生/一時停止は**オレンジ塗りの大円（72px）**、前後は白丸ボーダー（56px）。⏮⏭ は連結音声内の**単語境界（オフセット）へシーク**（境界配列を保持）。
- **粒度トグル `50語 / 100語`**: 選択中はティール塗り、非選択は枠線のみ。範囲（1–50 / 51–100…）は … メニュー or トグル長押しで切替（下部を散らかさない）。
- **✓ オフライン**表示: 端末内データのみで動く安心材料（散歩＝電波不要）。最下部に控えめに。
- 散歩用途の主役画面。ボタンは大きく、選択操作は下部にまとめ、再生中は触らずに済む構成。オレンジは「再生中の弧・ドット・一時停止ボタン」だけに使い、他はティール/text系に抑える。

## 6. 配色【一部適用】（Hearbit: ティール × オレンジ 2色運用）

CSS 変数で定義。ライト/ダークは `prefers-color-scheme` で自動 + 手動トグル（`data-theme` 属性で上書き）。
屋外視認性のため**コントラストを高め**、基調は彩度を抑えたティール（学習向けの落ち着き）。原本は `data/brand.md`。

### 6.0 状態を色で表す（最重要ルール）
Hearbit の配色は **2色の役割分担**で成り立つ。この使い分けを全画面で徹底する。

| 色 | 意味 | 具体的な使いどころ |
|---|---|---|
| **ティール `--accent`** | 通常 / 選択 / ブランド | ロゴ・戻る/アクションアイコン・通常の再生ボタン・選択タブ・トグルON・主ボタン塗り・円形リングの背景トラック |
| **オレンジ `--active`** | **いま再生中（アクティブ）** のみ | 再生中の単語ハイライト（セル/行）・一時停止ボタン・再生波形アニメ・円形プログレスの経過弧と先端ドット・ミニプレーヤーの再生波形と⏸ |

- **オレンジは「音が今そこで鳴っている」印**。選択やフォーカス、ホバーには**使わない**（それはティール）。
- これにより、画面のどこがアクティブかが色だけで即分かる（散歩中のチラ見・机での一覧確認の両方に効く）。
- オレンジの正確な階調はモック基準。実装時に下記トークンでコントラストを検証して確定する。

### 6.1 ライト
```
--bg            #F7F8FA   画面背景
--surface       #FFFFFF   カード/セル
--surface-2     #EEF1F5   セクションヘッダ/淡い面
--border        #D9DEE5   罫線
--text          #1A1D21   主テキスト（対背景 コントラスト比 ≥ 12:1）
--text-sub      #5B6470   補助テキスト（≥ 4.5:1）
--accent        #0E7C86   通常/選択/ブランド（ティール）
--accent-on     #FFFFFF   アクセント上の文字
--accent-weak   #D7EEF0   ティールの淡い塗り（本アイコンチップ等）
--active        #E8722C   いま再生中（オレンジ）
--active-on     #FFFFFF   オレンジ上の文字/アイコン
--active-weak   #FBE6D6   再生中セル/行の淡いオレンジ塗り
--danger        #C0392B   削除等
```

### 6.2 ダーク
```
--bg            #0E1116
--surface       #171B21
--surface-2     #1E242C
--border        #2A313B
--text          #F2F4F7   （対背景 コントラスト比 ≥ 13:1）
--text-sub      #9AA4B2   （≥ 4.5:1）
--accent        #2BC2CE   （暗背景で見やすい明るめティール）
--accent-on     #06232A
--accent-weak   #123A40
--active        #F0853C   （暗背景で見やすい明るめオレンジ）
--active-on     #2A1405
--active-weak   #3A2415
--danger        #E5675A
```

### 6.3 コントラスト方針
- 本文/番号は背景比 **4.5:1 以上**、大きな数字は 3:1 以上を厳守。
- 再生中セル/行は「淡いオレンジ塗り + オレンジのアクセント/アイコン + 波形」の複合表現で、**色だけに依存しない**（波形の動き・⏸アイコン・時間表示でも判別可能）。色覚特性に配慮。
- ティールとオレンジは色相が離れており、両立時も判別しやすい。ただし両者を隣接で多用せず、オレンジは常に「1箇所＝いま鳴っている所」に限定して情報過多を防ぐ。
- 屋外は明るいので、ライトでは背景と面の差を弱め・文字を濃く。ダークは黒すぎない `#0E1116`（有機ELの視認確保）。

## 8. 実装メモ（frontend-dev 向け）

- レイアウトは CSS Grid / Flexbox。番号グリッドは `grid-template-columns: repeat(auto-fill, minmax(72px,1fr))` で列数自動調整。
- ミニ/全画面プレーヤーは**同一の再生状態を共有**（1つの Audio 要素 + 状態オブジェクト）。DOM上で拡大/縮小するだけにし、再生を途切れさせない。
- スクロールは各画面のコンテンツ領域のみ（ヘッダ sticky、ミニプレーヤー fixed）。
- Safe-area 対応: `padding-bottom: calc(64px + env(safe-area-inset-bottom))` を一覧に。
- 再生位置は `segments.json` の `start`/`end` を使い、Audio の `currentTime` を start に設定 → `end` 到達で停止/次へ（`timeupdate` 監視）。分割ファイルではなく元音声のオフセット再生を基本とする（CLAUDE.md 準拠）。
- アニメーションは控えめ（150–200ms・イージング標準）。学習集中を妨げる派手な演出はしない。再生波形は SVG/CSS の軽量なイコライザーアニメで、再生中のみ動かす（停止で静止）。
- アクセシビリティ: 各操作ボタンに `aria-label`、番号セルは `role="button"` + `aria-label="ページ1 単語3 通し128"`。フォーカスリング可視。

### ブランド実装メモ（Hearbit）
- **ロゴ**: 波形アイコン + ワードマーク。SVG で用意（アイコン単体版＝PWA アイコン/favicon 兼用、横組み版＝ヘッダー用）。アイコンは `currentColor`/CSS変数で `--accent` に追従させ、ダーク対応を1アセットで済ませる。
- **円形プログレス（5.3）**: SVG `<circle>` の `stroke-dasharray`/`stroke-dashoffset` で描画。背景トラック=`--accent` 薄め、経過弧=`--active`、先端ドット=`--active`（弧の終点に小円を配置）。中央の単語はリング内に絶対配置。
- **色トークン**: §6 の CSS 変数をそのまま使用。`--active*` は「再生中」限定（§6.0）。選択/フォーカスに `--active` を使わない。
- **manifest**: `name: "Hearbit"`, `short_name: "Hearbit"`, `theme_color: #0E7C86`(ティール), `background_color` はライト `--bg`。アイコンはロゴのアイコン単体版。

### 実装優先度
1. ①→②→③(機能A・ミニ/全画面) の縦導線と番号グリッド・タップ再生（当初の悩みを最短で解決）。
2. Media Session（ロック画面/イヤホン前後）。
3. ②聞き流しタブ + ③機能B（連結再生・チャンク選択）。
4. 空状態/追加フロー/準備状態インジケータ。
5. 任意: 速度・リピート・ページインデックス・折りたたみ。
